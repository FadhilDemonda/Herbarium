# Audit UI Herbarium

Mode antislop: AFTER (pilihan sesi). Kode aplikasi tidak diubah; perbaikan menunggu persetujuan nomor temuan.

## Checklist audit

- [x] Baca PRD, DESIGN-PRD, aturan repo, dan implementasi UI.
- [x] Jalankan lint, build, dan detector statis.
- [x] Periksa render desktop, tablet, mobile, dan kedua tema.
- [x] Ukur kontras dan uji keyboard serta kontrol utama di browser terisolasi.
- [x] Catat temuan bernomor, aturan, prioritas, bukti, dan rekomendasi.
- [x] Laporkan keterbatasan verifikasi dan minta persetujuan nomor perbaikan.

## Ruang lingkup dan metode

- Sumber kebenaran: `docs/PRD.md`, `docs/DESIGN-PRD.md`, `docs/AGENTS.md`, serta kode saat audit.
- Surface: pustaka query, kartu/tabel, drawer detail, pencarian, login, form query, dan Master Data.
- Mode surface: Operate. Arah yang dinilai: hangat, tenang, fokus pada SQL; ENERGY 1 / RHYTHM 1 / MOTION 1, diturunkan dari brief, bukan arah desain baru.
- Chromium 159 melalui Playwright, viewport emulasi 360, 768, dan 1280 CSS px. Kedua tema diperiksa pada pustaka, detail, dan Master Data; detail diuji pada 360/1280, Master Data pada 360/768/1280.
- Data browser berasal dari JSON yang sudah ada di repo. Endpoint GAS diganti dengan endpoint audit pada proses Vite, lalu seluruh permintaan GAS dicegat. Sesi editor memakai token placeholder hanya di browser terisolasi. Tidak ada kredensial nyata atau operasi tulis ke backend.
- Uji kegagalan hapus memakai respons error simulasi. Uji offline membatalkan permintaan jaringan.
- Tidak memasang dependency baru atau mengubah source aplikasi. Skrip, screenshot, dan JSON bukti berada di `%LOCALAPPDATA%\Temp\opencode\herbarium-ui-audit*`.

## Temuan bernomor

### 1. HIGH / P1: Klaim verifikasi dan koneksi tidak berasal dari status nyata

- **Aturan:** R-36, R-38. Klaim selalu tampil tanpa bukti atau state yang mendukungnya.
- **Lokasi:** `src/components/QueryDetail.jsx:93,118-121,155-158`; `src/components/Sidebar.jsx:103-106`; `src/components/Header.jsx:68,156`.

Versi `v2.4` dan peran `Data Analyst` ditulis statis; versi package adalah 1.0.0 dan PRD tidak memiliki role. Author fallback `data_team` dan engine PostgreSQL juga bukan metadata query yang diverifikasi.
- **Dampak:** Pengguna dapat mempercayai SQL sebagai teruji atau mengira cache sebagai data live.
- **Rekomendasi:** Hapus klaim yang tidak memiliki sumber; bedakan sinkronisasi, cache/offline, dan kegagalan. Tampilkan pengedit terakhir dari data, bukan identitas rekaan. Jangan menambah sistem role/verification di luar PRD.
- **Kategori / command:** Implementation Integrity; `/impeccable harden`, `/impeccable clarify`.

### 2. HIGH / P1: Popularitas dan metadata parameter SQL dihitung dengan tebakan

- **Aturan:** R-17, R-38. Angka/rincian teknis yang disajikan sebagai fakta tidak punya sumber yang sesuai.
- **Lokasi:** `src/App.jsx:385-389,550`; `src/components/QueryDetail.jsx:235-245,274-276`; `src/lib/syntax.js:75-98`.

Kolom DATE/STRING, CURRENT_DATE/`''`, serta WAJIB ditentukan hanya dari nama parameter, bukan SQL/default sebenarnya. Fallback lineage memakai kategori sebagai nama tabel. Ekstraksi tabel dibatasi 10, tetapi jumlahnya ditampilkan sebagai total tanpa label batas.
- **Batas bukti:** Seed yang tersedia tidak mengandung placeholder Jinja sederhana yang cocok dengan regex; bagian tebakan parameter diverifikasi dari kode, bukan diklaim sudah tampil pada browser.
- **Dampak:** Urutan popularitas menyesatkan dan pengguna dapat mengikuti petunjuk parameter yang salah.
- **Rekomendasi:** Hilangkan opsi popularitas tanpa hitungan asli. Jangan menampilkan tipe/default/kewajiban parameter yang tidak diketahui; labeli hasil ekstraksi sebagai indikasi atau tampilkan hanya informasi yang benar-benar diketahui. Gunakan state kosong, bukan lineage rekaan.

### 7. HIGH / P1: Dialog tidak mengelola fokus; Escape tidak konsisten

- **Aturan:** R-32, R-26; WCAG 2.4.3 dan pola modal WAI-ARIA.
- **Lokasi:** `src/components/QueryDetail.jsx:36-54`; `src/components/LoginModal.jsx:17-39,124`; `src/components/CommandPalette.jsx:40-72`; `src/components/QueryFormModal.jsx:110-128`; `src/components/DeleteConfirmDialog.jsx:8-16`; `src/components/MasterDataPage.jsx:354-503,505-571`; `src/App.jsx:88-97,593-622`; `src/components/Header.jsx:18-27,161-205`.
- **Bukti:** Drawer terbuka tetapi fokus tetap pada tombol Buka Detail di halaman belakang. Shift+Tab dari tombol tutup drawer berpindah ke belakang overlay. Pada login, urutan Tab dari username melewati password lalu submit, kemudian keluar dialog; tombol lihat password dilewati karena `tabIndex=-1`. Modal form/hapus Master Data tidak menutup dengan Escape. Menu Ekspor tetap terbuka setelah Escape. Kode menu pengguna juga hanya menutup lewat klik luar, tanpa pengelolaan keyboard menu.
- **Dampak:** Keyboard/screen reader dapat mengoperasikan halaman belakang alih-alih modal; penutupan dan pemulihan fokus tidak dapat diprediksi.
- **Rekomendasi:** Terapkan primitive dialog bersama: autofocus, focus trap, pemulihan fokus, isolasi background, nama dialog, dan Escape hanya untuk overlay teratas. Lengkapi navigasi serta penutupan keyboard menu.
- **Kategori / command:** Accessibility; `/impeccable harden`.

## Pola sistemik

- Masalah konten bukan sekadar gaya: beberapa label mengklaim sesuatu yang aplikasi tidak tahu atau tidak lakukan (#1-3).
- Dialog dibuat terpisah tanpa fondasi fokus/error bersama (#7, #9, #11).
- Layout desktop dipersempit tanpa mempertahankan seluruh aksi utama di ponsel (#4, #5, #10).
- Token sudah ada, tetapi kartu menggunakan sistem paralel yang menyulitkan kontras dan konsistensi (#6, #12, #13).

## Hal yang sudah baik dan false positive yang dihindari

- Jumlah koleksi, kategori dominan, dan pembaruan terakhir pada StatsBanner dihitung dari data query nyata; bukan statistik palsu.
- Palette melakukan pencarian fuzzy dan Enter membuka hasil yang dipilih.
- Salin menggunakan SQL dari sumber; clipboard browser cocok dengan salah satu SQL yang ada. API Clipboard memiliki fallback di kode.
- Favorit dengan klik mouse, filter kategori/URL, pergantian grid/tabel, serta unduhan CSV/JSON berfungsi dalam uji browser.
- Toggle tema dan persistensi setelah reload berfungsi. Identitas warna, Plus Jakarta Sans, JetBrains Mono untuk SQL, serta lucide-react memang diminta brief; tidak ditandai sebagai slop hanya karena populer.
- `outline:none` pada sort tidak dilaporkan otomatis sebagai fokus hilang: computed style saat keyboard focus masih menunjukkan outline global 2px.
- Prism melakukan escaping pada jalur highlighting, dengan fallback HTML escape; penggunaan dangerouslySetInnerHTML di detail tidak otomatis berarti SQL mentah tidak aman.
- Empty state tampil ketika respons server adalah daftar kosong. Namun kalimat untuk viewer masih menyuruh klik Tambah Query yang tidak tersedia; catatan UX ini belum dijadikan permintaan perbaikan tersendiri.

## Pemeriksaan dan batas bukti

- `npm.cmd run lint`: exit 0.
- `npm.cmd run build`: exit 0; CSS 66,23 kB (gzip 11,67 kB), JS 410,28 kB (gzip 114,56 kB). Ini ukuran output build, bukan Web Vitals.
- `impeccable detect --json src index.html`: exit 0, `[]`. Tidak ada temuan detector untuk disembunyikan atau diperbaiki otomatis.
- Browser: tidak ada console error di alur normal; satu pageerror sengaja direproduksi lewat kegagalan hapus simulasi (#11).
- Kontras: pasangan yang disebutkan dihitung dari token dan computed style browser setelah transisi tema selesai. Bukan klaim seluruh pasangan warna sudah lulus.
- Belum diuji: backend GAS nyata, kredensial/login sukses nyata, penulisan CRUD sukses nyata, perangkat sentuh fisik, gesture sentuh sintetis, Safari/Firefox, pembaca layar nyata, zoom browser 200%, mobile keyboard, semua kombinasi preset/state, Lighthouse, Web Vitals, dan performa 500 query.
- Atribut `lang=id`, judul, dan viewport zoom tersedia. Pustaka belum memiliki h1, dan Master Data belum memakai landmark main; dicatat untuk scope semantik lanjutan, tidak dipakai untuk mengarang hasil screen reader.
- Audit ini bukan pengiriman UI baru atau persetujuan Delivery Gate. Temuan dibiarkan terbuka sesuai mode AFTER; tidak ada klaim seluruh kontrol/tema/breakpoint lulus.
